# Пинок — описание продукта

> Семейное приложение, где все делят домашние дела между собой, пинают друг друга
> и получают звёзды за внимательность к дому.

Платформа: **только нативное приложение** (App Store + Google Play). Аудитория международная.
Telegram-бот — возможно позже, отдельным клиентом к тому же бэкенду. Mini App не будет.

---

## 0. Миссия

**Сделать невидимый труд видимым.** Заметить, помнить, спланировать, распределить, напомнить,
объяснить, где что лежит, — это работа, и чаще всего её делает женщина. В Пинке каждое такое
действие записывается, приносит звёзды и попадает в «Отчёт по дому».

## 1. Главные принципы

1. **Все равны.** Любой взрослый может создать дело, назначить его кому угодно и пнуть.
2. **Пинок — это только подпинывание.** «Давай, делай». Пинок никогда не награда и не валюта.
3. **Звёзды ⭐ — это награда.** Даются не только за сделанное, но и за то, что *заметил*:
   проверил запас, кинул флаг, перевёл стирку в следующий статус.
4. **У дома есть температура.** Всё может быть 🟢 / 🟡 / 🔴 / 🔥. Задача семьи — держать дом зелёным.
5. **Отметить что-то — меньше 3 секунд.** Иначе никто не будет пользоваться.
6. **Весело, а не токсично.** Пинки и наказания — игра, у которой есть «оспорить» и «амнистия».

## 2. Сущности

| Сущность | Что это | Пример |
|---|---|---|
| **Семья (дом)** | группа людей и всё их хозяйство | «Шафеевы» |
| **Участник** | взрослый, ребёнок или гость | мама, папа, Маша, уборщица |
| **Дело** | назначено конкретному человеку, разовое или повторяющееся | «Вынести мусор — каждый день — папа» |
| **Флаг** | сигнал без исполнителя, любой может взять | «Стирка готова — кто разберёт?» |
| **Прибор** | вещь со статусами, которые переключают все | стиралка, посудомойка, сушилка |
| **Запас** | то, что заканчивается, с порогами цвета | помидоры: 5 шт, жёлтый ≤2, красный ≤1 |
| **Объект** | имущество с регламентом обслуживания | машина, сад, питомец, котёл |
| **Место** | комната → шкаф → полка, с фото и метками | «Ванная → шкаф под раковиной» |
| **Инструкция** | пошаговая карточка с фото | «Как ставить чёрную стирку» |
| **Пинок** | напоминание человеку (авто или ручное) | 🦶 «Мусор сам себя не вынесет» |
| **Звёзды** | награда, ведётся как журнал начислений | +3 за взятый флаг |
| **Ведро хаоса** | список нелюбимых дел каждого человека | «Помыть духовку» |
| **Наказание** | что выпало за невыполнение | дело из ведра, штраф звёздами, долг в копилку |

## 3. Дела

### 3.1 Создание дела

Создатель указывает только:

1. **Что** — название (+ иконка, заметка, привязка к прибору/объекту — необязательно).
2. **Кто** — исполнитель (можно себя).
3. **Когда делать** — один раз к сроку, или повтор: каждый день / по дням недели / каждые N дней / раз в месяц.
4. **Как пинать** — расписание пинков (см. 3.2).

Наказание при создании **не задаётся** — работают общие правила семьи (см. 7).

### 3.2 Расписание пинков

Два слоя: **база** + **нарастание к сроку**.

| Дело | Когда делать | Как пинать |
|---|---|---|
| Мусор | каждый день | 8:00, 13:00, 19:00, пока не сделано |
| Полить цветы | по субботам | суббота 10:00, один раз |
| Оплатить садик | до 25-го | раз в неделю → за 3 дня каждый день → в последний день каждый час 9–21 |
| ТО машины | 15 ноября | за неделю, за день, в день утром |

**Готовые варианты одной кнопкой:** «Один раз» · «Утром» · «Утро / обед / вечер» ·
«Нарастает к сроку» · «Каждый час до победного». Плюс ручная настройка.

**Правила, которые работают всегда:**
- Сделано → пинки прекращаются.
- «Отстань на час» → следующий пинок откладывается.
- Тихие часы у каждого человека (по умолчанию 23:00–7:00). Будить — только если автор явно включил.
- После срока: продолжать пинать (по умолчанию) или просто сообщить автору.

Формат хранения (`tasks.kick_plan`):

```json
{
  "base": { "type": "times", "times": ["08:00", "13:00", "19:00"] },
  "escalation": [
    { "before": "P3D", "type": "times",  "times": ["10:00"] },
    { "before": "P1D", "type": "every",  "minutes": 60, "between": ["09:00", "21:00"] }
  ],
  "overdue": "keep_kicking",
  "wake_up": false
}
```

### 3.3 Температура («огонь»)

| Уровень | Когда | В интерфейсе |
|---|---|---|
| 🟢 Спокойно | до срока | обычная карточка |
| 🟡 Пора | срок сегодня / скоро | жёлтая рамка, лёгкое покачивание |
| 🔴 Горит | просрочено | красная, дрожит, короткая вибрация при открытии |
| 🔥 Пожар | сильно просрочено | огонь по краям экрана, сильная дрожь, длинная вибрация, полноэкранная карточка |

Ограничения платформ: собственный рисунок вибрации в push есть только на Android.
На iPhone — свой звук пинка и *time-sensitive* уведомления; полный эффект — при открытии.

## 4. Пинки 🦶

### 4.1 Автоматические
Приходят по расписанию дела. Текст — случайная фраза по уровню огня.

### 4.2 Ручной «Пнуть ещё»
Кнопка у каждого дела, назначенного другому человеку. Пинки идут **комбо-сериями**:

| В серии | Уровень |
|---|---|
| 1 | лёгкий пинок |
| 2 | пинок с разбега |
| 3 | пинок с вертушки |
| 4+ | 🚀 космический пинок |

- Получатель видит полноэкранную анимацию: ботинок влетает в экран, вибрация, звук (выключается).
- Случайные фразы: «Помидоры плачут», «Стирка ждёт тебя уже 3 ч 14 мин».
- **Ответ в одно касание:** «Уже бегу!» · «Через 10 минут» · «Отстань 😤» — автор видит ответ.
- После 5 пинков подряд по одному делу — пауза 10 минут: «Кажется, он уже понял 😅».
- Сделал в течение 15 минут после пинка → бонусные звёзды «быстрая реакция».

---

## 5. Флаги 🚩

Сигнал без исполнителя. Два вида:
- **Заметка** — «Закончилась туалетная бумага», «Стирка готова — кто разберёт?».
- **Просьба со сроком** — «Чёрная стирка, рабочая одежда к завтра 8:00» (краснеет к сроку).

Жизненный цикл: `открыт → взят (кем-то) → сделан` (или `отменён`).
«Беру!» превращает флаг в дело этого человека, остальным приходит уведомление.
Чем дольше флаг горит, тем больше звёзд за то, чтобы его взять.

---

## 6. Приборы со статусом

Пример — стиральная машина:

```
свободна → стирается → 🔴 готово, разобрать → сушится → 🟡 сложить → свободна
```

- Статус переключает кто угодно, каждый переход даёт звёзды.
- Красные статусы автоматически становятся флагами («кто разберёт?»).
- Время в красном статусе повышает награду.
- Шаблоны: стиралка, сушилка, посудомойка, робот-пылесос, свой прибор.
- Позже: QR/NFC-наклейка на приборе — поднёс телефон, статус переключился.

## 7. Звёзды ⭐ и наказания

### 7.1 Начисления (черновик, всё настраивается)

| Действие | Звёзды |
|---|---|
| Проверил запас | +1 (+2, если давно никто не проверял) |
| Кинул флаг (кто-то другой подтвердил/взял) | +2 |
| Взял флаг | +3 … +10, растёт с огнём |
| Сделал своё дело | +3 |
| Сделал чужое дело | +5 |
| Перевёл прибор в следующий статус | +2 |
| Купил позицию из списка | +2 |
| Быстрая реакция на пинок (≤15 мин) | +2 |
| **Спланировал:** создал дело, и его сделали | +1 автору дела |
| **Напомнил:** пнул, и дело сделали в течение часа | +1 тому, кто пнул |
| **Объяснил:** написал инструкцию в Гиде, её открыли | +1 автору |
| Отработал наказание | +1 |

**Против накрутки:** повторная отметка того же самого за короткое время — 0;
за флаг звёзды только после подтверждения другим; кнопка «спасибо» = бонус.
Все начисления считаются **на сервере**, приложение их только показывает.

### 7.2 Командная игра
- **Цель семьи на неделю:** «500 ⭐ → пицца-вечер».
- **Титулы недели:** «Глаз-алмаз» (больше всех заметил), «Спасатель» (больше всех флагов), «Хозяин стирки».
- **Магазин наград для детей:** награды задают взрослые, детские звёзды подтверждает взрослый.

### 7.3 Отчёт по дому (невидимый труд)

Главный экран вкладки «Семья». За неделю/месяц для каждого человека:

> **Ира — 61% работы по дому**
> 18 сделала · 12 заметила · 25 спланировала · 30 напомнила

Четыре вида труда: **сделал** (видимый) · **заметил** · **спланировал** · **напомнил** (невидимый).
Доля считается по всем четырём, а не только по сделанному.

### 7.4 Ведро хаоса и наказания
- У каждого своё **ведро нелюбимых дел**. Заполняет сам человек, или семья предлагает — он подтверждает.
- **Общие правила семьи** (в настройках, не при каждом деле): сколько пропусков допустимо и что выпадает:
  🪣 дело из ведра · 📉 штраф звёздами · 💸 долг в копилку (только учёт, деньги вне приложения) ·
  📚 пройти инструкции + викторину · 😇 ничего.
- Наказание выпадает с анимацией (ведро/колесо) и встаёт в план как обычное дело — со своими пинками и огнём.
- **Оспорить** («болел», «не было дома») — автор дела может простить. **Амнистия** — раз в месяц.
- Детям наказания назначают только взрослые.

## 8. Онбординг

Цель первых 3 минут: **показать невидимый труд цифрой** и **сразу перераспределить дела**.

### Для того, кто создаёт дом
1. **Привет** — «Пинок делает невидимую работу по дому видимой».
2. **Регистрация** — имя + Apple / Google / почта.
3. **Кто живёт дома** — название дома и люди (партнёр, дети…). **Людей можно добавить до того,
   как они установили приложение**: им сразу можно раздавать дела.
4. **Что есть дома** — ☐ стиралка ☐ сушилка ☐ посудомойка ☐ робот-пылесос ☐ дети ☐ питомцы ☐ машина ☐ сад.
   Приборы появляются только отмеченные (авто-стиралки нет).
5. **Расскажи голосом** — «Как проходит твоя обычная неделя по дому? Что делаешь, о чём помнишь,
   что бесит? Что обычно заканчивается?» → ИИ раскладывает рассказ на дела: кто, как часто, видимое/👻 невидимое.
   Из «что заканчивается» собирается стартовый список запасов.
6. **«Это тоже ты?»** — карточки с типичными невидимыми делами (дни рождения и подарки, врачи и прививки,
   заметить, что кончилось, одежда ребёнку, документы для школы…) → **Я / Не я / Нет такого**.
7. **Вот правда** — «На тебе 34 дела в неделю, 21 невидимое. Это 78% работы по дому».
   **Видит только тот, кто проходил**; поделиться с семьёй — по желанию.
   Снимок сохраняется, чтобы через месяц показать «было 78% → стало 55%».
8. **Перераспределим?** — те же дела: назначить человеку, как часто, как пинать. Дела создаются сразу.
9. **Позови семью** — у каждого своя ссылка: «Ира дала тебе пинок 🦶 — у тебя уже 3 дела».

### Для приглашённого
1. Ссылка → установка → вход. Профиль-заготовка с его делами становится его профилем.
2. 3 карточки обучения: пинок (с анимацией), флаг, звёзды.
3. Игровой тон, без обвинений: «Добро пожаловать в команду дома. Первый, кто наберёт 50 ⭐, выбирает фильм».

## 9. Календарь

Важные даты обычно помнит один человек — это тоже невидимый труд. Заполняется один раз,
дальше всё приходит само и всем.

**Событие = дата + кто видит + напоминания + подготовка.**

> 🎂 **День рождения бабушки, 14 марта, каждый год** — видит вся семья
> Напоминания: за 30 дней, за 7, за 1, в день утром (настраивается у каждого события)
> Подготовка (сама становится делами с пинками):
> за 30 дней «Выбрать подарок» → Саша · за 7 дней «Купить подарок» → Саша · за 1 день «Позвонить» → Ира

Виды: 🎂 дни рождения и годовщины · 🏫 школа и садик · 🩺 врачи и прививки · 🚗 техосмотр, страховка · ✈️ поездки.
Вкладка «Дела» → **«Дела и календарь»** (переключатель Список / Календарь).
Кто завёл событие и расписал подготовку — звёзды «спланировала» в Отчёт по дому.

## 10. Запасы

- Количество + единица + пороги (жёлтый / красный) или просто «много / мало / нет».
- **Разведка** — Пинок сам спрашивает, человеку не нужно помнить, что проверить:
  - карточки-свайпы «Рейд по кухне»: ← кончается · мало · много →, 10 продуктов за 15 секунд, комбо за скорость;
  - сами выскакивают: карточка на «Доме», push («Ты на кухне? Глянь молоко, +2 ⭐»), виджет;
  - сначала спрашивает то, что дольше всех не проверяли (за это больше звёзд); вопросы распределяются на всех;
  - задание дня «Проверь 3 вещи», стрик 7 дней → титул «Глаз-алмаз»;
  - «много», а через час у другого «нет» → звёзды за ту проверку сгорают.
- Отметка одним касанием. Красное → автоматически в список покупок.
- «Куплено» → снова зелёный. У каждого запаса есть **место** — видно, где лежит и куда положить.

## 11. Гид по дому («Как у нас заведено»)

- **Карта:** дом → комнаты → места хранения; фото/схема с метками. Поиск «где порошок?» → фото с мигающей меткой.
- **Инструкции:** пошаговые карточки с фото, привязаны к приборам и делам.
- **Обучение:** «курс новичка», викторины, собранные из карты и инструкций, значки.
- **Гостевой доступ:** уборщица/няня видит карту, инструкции и свои дела. Без звёзд, ведра и ленты.

## 12. Объекты

Машина, сад, питомец, ребёнок, котёл, бассейн. У каждого — регламент обслуживания
(«ТО раз в год или каждые 10 000 км», «полив с мая по сентябрь»), из которого сами появляются дела и флаги,
и история на карточке объекта.

## 13. Экраны

**Вкладки:**
1. 🏠 **Дом** — что горит, открытые флаги, мои дела на сегодня, приборы, цель недели.
2. ✅ **Дела и календарь** — мои / все / по людям; события и подготовка к ним.
3. 🥫 **Запасы** — остатки, список покупок.
4. 🗺 **Гид** — карта, инструкции, викторины.
5. 👨‍👩‍👧 **Семья** — **отчёт по дому (невидимый труд)**, звёзды, титулы, ведра, копилка, лента, настройки.

**Центральная кнопка «+»:** Дело · Флаг · Запас · Прибор.

**Полноэкранные моменты:** входящий пинок, 🔥-карточка, выпадение наказания, ачивка.

## 14. Дизайн

Продолжаем стиль Mini App (`webapp/index.html`): **ретро-аркада, 8 бит**.
- Фон `#0a0a0a`, карточки `#161616`, неон `#39ff14`.
- Добавляем цвета огня: жёлтый `#ffd60a`, красный `#ff3b30`, «пожар» `#ff6a00`; звёзды — золото.
- **Press Start 2P** — только для заголовков, цифр, комбо пинков. Основной текст — читаемый шрифт
  (Inter или аналог), минимум 14–16 pt.
- Игровые метафоры: комбо пинков, «LOW HP» у горящих дел, ведро-автомат, уровни викторин.

## 15. Техническая архитектура

| Часть | Решение | Почему |
|---|---|---|
| Приложение | **Expo (React Native) + TypeScript** | анимации, вибрация, push, виджеты, один код на iOS и Android |
| Вход | **Supabase Auth**: Sign in with Apple, Google, email | Apple требует «Войти через Apple», если есть другие соцсети; не пишем свою авторизацию |
| Данные | **Supabase Postgres + RLS** | приложение читает напрямую, доступ только к своей семье |
| Звёзды и действия | **функции в базе (RPC)** | начисления нельзя подделать с телефона |
| Сервер | **Supabase Edge Functions** + **pg_cron** | голосовая диагностика, планировщик пинков раз в минуту, push через Expo Push; отдельный хостинг не нужен |
| Подписки | **RevenueCat** | App Store + Google Play одной библиотекой |

Структура репозитория:

```
/app        — Expo-приложение
/supabase/functions — серверный код (Edge Functions)
/supabase/migrations — миграции базы
/docs       — этот документ
```

База — **существующий проект Supabase**, таблицы старого бота удаляются скриптом `supabase/reset_and_install.sql`.
Код старого бота (`handlers/`, `index.js`) после этого не работает; серверная часть — Edge Functions в `supabase/functions`.

## 16. Этапы

| **1. Ядро** ✅ | вход, семья, дела с расписанием пинков, ручной «пнуть ещё» с комбо, огонь, флаги, приборы, звёзды, лента |
| **2. Онбординг и невидимый труд** | голосовая диагностика, «Это тоже ты?», «Вот правда», перераспределение, люди-заготовки, личные приглашения, Отчёт по дому, звёзды за «спланировал» и «напомнил», сервер пинков + push |
